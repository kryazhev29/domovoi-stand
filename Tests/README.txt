Самопроверка стенда без оборудования (Python 3.11, стандартная библиотека)

Из каталога Скрипты:
  python -B -X utf8 Tests/test_stand.py
  python -B -X utf8 Tests/test_end_to_end.py

Первая команда проверяет смену TCP-сеанса, порядок проверок, сохранение триггеров,
причины отказа выхода и выгрузки журнала, незавершённую фотографию.
Вторая запускает настоящие test_server.py --headless и fake_board.py на временном
порту 127.0.0.1. Прошивка, настройки, фото и отчёты создаются в TEMP и удаляются.
Нормальная модель проходит все 19 проверок, включая синхронизацию настроек.
Проверяются отдельно переподключение без закрытия старого сокета, потеря ответа 11,
зависание, неверный ответ 99, старый хвост праздников, отсутствие прогресса обновления,
чужая сборка и отсутствие события 136. Полный прогон занимает примерно 1,5–2 минуты.

Ручной локальный пример, два терминала:
  python -B test_server.py --headless --bind 127.0.0.1 --port 15010
  python -B fake_board.py --port 15010 --fault reconnect-open

Один автоматический прогон и завершение процесса:
  python -B test_server.py --headless --bind 127.0.0.1 --port 15010 --run праздники журнал --json result.json -o result.txt

--run all: прежний обычный набор; --run full: все проверки, включая изменение платы.
Для полной проверки нужны --firmware, --config, --phone. Не применять full к реальной
плате без согласованного сценария: меняются таблицы, выходы, отправляется SMS, происходит
перезапуск и обновление. Для самопроверки указанные параметры создаёт test_end_to_end.py.
Обычный запуск без --run сохраняет окно и управляющий порт 127.0.0.1:15011.

--fault lost11 теряет только ответ на команду 19: исправный сервер всё равно даёт
«годно» по биту 11, пакетам 4, новой регистрации, сборке и событиям 132/135/136.
--fault reconnect-open тоже должен пройти: новый сокет вытесняет прежний.
Остальные проверенные неисправности должны дать «не годно».

Это проверка логики стенда и обмена TCP на модели. Она не подтверждает работу реле,
SMS оператора, камеры, модема, Flash и загрузчика физической платы.
